# 练迹 · LiftLog

一款中文原生 Android 离线力量训练日志。使用 Kotlin、Jetpack Compose + Material 3、Room（SQLite）。没有账号、服务器或网络权限。

## 直接安装

- 手机需为 Android 8.0（API 26）或更新版本。将提供的测试版 APK 下载到手机，打开安装；如果系统询问，仅允许当前安装来源安装该 APK。
- 先打开「周计划」，选今天是星期几，添加一个动作。可填自重（0 kg），休息时间填 0 秒则不会启动计时。
- 回到「训练」开始，做完一组点默认值按钮即可记组。实际重量或次数不同，用手动记录；已记的组也可更正或撤销。
- 「日历」支持查看某一天的明细，并可覆盖单日计划、设为休息日或恢复使用周计划。开始训练后固定当天快照，后续编辑周计划不会覆盖它。
- 「统计」按本月或累计筛选。每个动作每天至少有一组实际记录才计一天；最大重量来自某一组的实际记录，同时显示次数和日期，不估算 1RM。
- 右上角「备份」可导出或恢复 JSON。恢复前会确认替换全部训练数据而非合并。卸载应用会清除本机数据，卸载前请先导出备份，备份文件请自行保管。

### 状态与计时

四种状态：待训练（蓝色空心圆）、部分完成（橙色菱形）、已完成（绿色勾）、休息日（灰色横线）。计入的是已记录的计划组数，不要求每组达到目标次数或重量；额外组也纳入最大重量与训练天数统计。以选中的日期记录历史，不会启动当前休息计时。

今日新增组后自动开始休息，支持加减 15 秒或跳过。「训练 → 提示音」可选择和试听内置提示音，调节应用内音量，或设为 0% 静音。设置保存在本机；实际响度也受手机的闹钟音量影响。计时以系统单调时间计算，切换到其他 App 不会暂停。到点后会循环播放所选提示音，直到在应用内弹窗或通知里点「停止提示音」；0% 音量只显示提醒，不播放。使用其他 App 时，在「训练 → 后台提醒」中允许通知，或另外选择允许「在其他应用上显示」来显示带停止按钮的小卡片。悬浮窗权限可随时撤销；只在休息提醒触发、练迹不在前台时使用，不访问其他应用的内容。两种提醒都没开放时仅在练迹内提醒。可点「测试 10 秒」然后切到视频验证，不会写入训练记录。横幅、悬浮窗和铃声可能受视频 App、勿扰、厂商后台限制、熄屏休眠和强制停止影响；Android 12 或更新版本可在「后台提醒」中开启系统的「闹钟和提醒」权限，让 Android 在练迹被暂停时也能投递到期事件。

## 打开源码与构建

在 Android Studio 中打开压缩包内的 `LiftLog` 根目录，选 JDK 17，安装 Android SDK Platform 35 和 Build Tools 35.0.0，等待 Gradle 同步。首次构建需要联网下载依赖，安装后 App 本身不需要联网。

Windows（PowerShell）：
```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

macOS / Linux：
```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

APK 位置：`app/build/outputs/apk/debug/app-debug.apk`。这是用于试装的调试签名构建，未发布到应用商店。也可以连接手机/模拟器后在 Android Studio 中直接运行。

## 建议手机验收

1. 周计划里给当天添加「卧推 60 kg × 10 次，2 组」，休息填 30 秒。
2. 开始后将实际第一组记为 60 kg × 8，观察立即计时；退到后台约 10 秒再返回，确认剩余时间减少。
3. 提前结束，查看当天为「部分完成」；继续训练并记第二组，观察自动成为「已完成」。
4. 变更本周同一星期几的计划，确认已开始这天的记录不变；在日历任选未开始的一天设置单次休息。
5. 两组同一动作在统计中只计 1 天。校验实际最大重量、次数、日期，并检查撤销后统计更新。
6. 导出备份，修改一个计划，再确认恢复。检查计划与历史回到备份状态；取消恢复则不改变数据。
